#### Scalar

- A scalar type represents a single value
- types:
  -- integers,
  -- floating-point numbers,
  -- Booleans,
  -- characters

Length Signed Unsigned
8-bit i8 u8
16-bit i16 u16
32-bit i32 u32
64-bit i64 u64
128-bit i128 u128
arch isize usize

i8 -> -(2^n - ^1) to 2^n - ^1 - 1 -> -128 to 127
u8 -> 0 to 2^n - 1 -> 0 to 255

- Signed and unsigned
  -- Signed -> positive/negative
  -- Unsigned -> only positive
